**Rule** (put verbatim into 7.2 step 8):

```
t      = max(not_before, now − 360 000)
c_max  = max(base, all history counters)
c_snap = max(base, history counters with accepted_at ≤ t)
later  = { history counters with accepted_at > t }
ok     = (c_max = 0 and received = 0) or (received > c_snap and received ∉ later)
```

   - checkpoint `time` outside `[not_before, not_after]` of the key.

6. Signature (`E_LOG_CHECKPOINT`).
7. Timestamp present → `Unsupported` (unchanged).
